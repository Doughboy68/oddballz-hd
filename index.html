ℹ️ ABOUT & CREDITS

The gameplay and the original Borland Pascal engine are Fred Kohler's. Brian Semotiuk converted the game to Windows, adapting the code where the port required it, working on it from around 1992–93 and finalising the build in 1994. It was never fully finished and was never released. Oddballz HD ports that engine to JavaScript, with the aim of finally finishing what was started over thirty years ago.

The matching, support and gravity rules are the original's, untouched. Around them: selectable board sizes, a game timer, high scores kept separately per mode and board, reworked levelling and scoring, and a number of long-standing bugs fixed. The presentation is rebuilt throughout — real-time 3D sphere physics, metallic shaders, dynamic space flight backdrops, Web Audio synthesis, smooth continuous motion in place of the original's step-by-step movement, and pieces that flip in place rather than pivoting end over end about a single ball.

Code and graphics/design copyright © Brian Semotiuk and Fred Kohler.
