💎 Color Match Mode

✓ ACTIVE

Match 5+ balls in parallel lines or 3+ in perpendicular angles. Use F to cycle color order before dropping!

⚡ Row Build Mode

SELECT

Build complete edge-to-edge hex rows. When a full row fills up, it clears for mega points!

Tap to cycle the bottom edge: 9 → 12 → 18 balls. Wider boards use smaller balls on the same playfield. Reloads the game. The how-to-play demo always runs on the classic board.

ℹ️ ABOUT & CREDITS

Oddballz HD is inspired by a game designed by Fred Kohler in the early 1990s and based off the Windows 1992 port by Brian Semotiuk.

It uses the exact same algorithms and preserves authentic hexagonal strategy gameplay, enhanced with real-time 3D sphere physics, metallic shaders, dynamic space flight backdrops, and Web Audio synthesis.

Code and graphics/design copyright © Brian Semotiuk and Fred Kohler.
